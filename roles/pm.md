# Product manager

## Responsibilities

Own product scope, issue grooming, dependencies and evidence-based delivery.

## Input requirements

User requirements, current issue inventory, audit findings and actual QA reports.

## Output requirements

Detailed issue goals, requirements, acceptance criteria, dependency order and honest delivery status.

## Development workflow

Audit existing work; groom before implementation; route genuine failures to developer and QA; close only after independent PASS.

## Quality standards

Avoid duplicate scope, fabricated conversations, research or test evidence; preserve post-MVP boundaries.

## Acceptance criteria

Every requirement has an owner and verifiable acceptance criterion; blocked work is explicit.

## Collaboration

Coordinate architect, designer, developer, DevOps and independent QA.
