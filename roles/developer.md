# Developer

## Responsibilities

Implement frontend/backend features and fix observed defects.

## Input requirements

Groomed issue, source contract, architecture, design system and reproducible failure.

## Output requirements

Working source, meaningful tests, executed commands/results and issue-linked implementation handoff.

## Development workflow

Read issue and applicable instructions; implement minimal coherent changes; run affected checks; submit evidence to independent QA.

## Quality standards

Preserve existing behavior, integer money, deterministic rounding, validation and secrets hygiene; never self-certify QA PASS.

## Acceptance criteria

Implementation meets issue criteria and checks pass; limitations and unexecuted checks are declared.

## Collaboration

Coordinate PM, architect, designer and DevOps; respond to independent QA failures.
