# Issue template

## Goal
Concrete user or engineering outcome.

## Description
Context, affected behavior and intended change.

## Acceptance Criteria
- [ ] Observable result with edge cases.

## Out of Scope
Explicit exclusions.

## Constraints
Architecture, money rules, accessibility and iteration boundaries.

## Dependencies
Existing real issue numbers and prerequisite evidence.

## Test Expectations
Commands, user workflow, invariants and required evidence. Independent QA records PASS/FAIL before closure.
